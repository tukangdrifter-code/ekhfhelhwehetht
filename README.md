# 丙級飛機修護術科 — 液壓管路拆裝 (p.2-33 ~ 2-34)
### 三、口述部分 — Oral Recitation Sections (3.1 / 3.2 / 3.3)

---

## 3.1 — (一) 拆裝前 (Before Disassembly) — full section

**1.** 應先將飛機靜電搭地，接著於搭地樁放電，並將電瓶電門開關給予關斷，拉起斷電器並拔除電瓶，使飛機斷電。

**2.** ⭐ *工作單題目* — 開始執行洩壓工作，洩壓前必須在相關開關及斷電器處掛上禁止操作掛籤，以確保工作安全。

**3.** ⭐ *工作單題目* — 拆裝液壓管路時，應將飛機之液壓系統之液壓開關與斷電器關斷，並將管路及液壓油箱內之液壓壓力卸除。

**4.** 液壓系統洩壓方式有下列六種：
1. 由飛機液壓系統之洩壓瓣洩壓。
2. 由飛行操縱系統（飛操系）洩壓 — 方向舵蹬舵洩壓、升降舵與副翼的操縱桿洩壓。
3. 方向舵踏板腳尖向前頂使主起落架煞車洩壓。
4. 由液壓管路內之洩壓閥洩壓。
5. 由液壓油箱洩壓閥洩壓。
6. 由儲壓器洩壓。

**5.** 以上程序完成後才可以執行拆除液壓管路作業。

**Main points to lock in:**
- Order: 靜電搭地 → 電瓶電門關斷 → 斷電器拉起 → 電瓶拔除
- Tag-out BEFORE pressure release: 掛禁止操作掛籤
- Shut hydraulic switch + breaker AND relieve pressure in lines + reservoir before touching lines
- **6 ways to depressurize** — know all six, in order: 洩壓瓣 / 飛操系 / 主起落架煞車 / 洩壓閥(管路) / 洩壓閥(油箱) / 儲壓器
- Nothing gets disassembled until ALL of the above is done

---

## 3.2 — (二) 拆卸過程 (Disassembly Process) — point 4 only

**4.** 完成後接下來就必須要口述給監評委員（拆卸後）：將結構端套上防塵套後，檢查已拆除之液壓管路，首先我們以由外而內的方式檢查，一、檢查管路外觀是否良好有無損傷。二、檢查管路兩端之螺牙與螺帽是否滑牙或損傷。三、檢查管內是否暢通。（這裡要請應試人員注意，一般液壓油均有毒且有腐蝕性，我們不可以用嘴吹，應用燈光照射法或是用低壓力之壓縮空氣來測試是否堵塞。）以上都是要邊做邊口述。

**Main points to lock in:**
- Cap ends with 防塵套 first
- Inspection order is **outside → inside** (由外而內): ① 外觀損傷 → ② 螺牙/螺帽滑牙損傷 → ③ 管內暢通
- ⚠️ Never blow into the line with your mouth — hydraulic fluid is toxic + corrosive. Use 燈光照射法 or low-pressure 壓縮空氣 instead.
- This entire step is done **while talking out loud** (邊做邊口述) — you'll be graded on saying it, not just doing it

---

## 3.3 — (三) 拆裝後 (After Reinstallation) — full section

**1.** 飛機液壓管完成應先確認液壓管外上圖案或文字是否仍為一直線，以避免液壓管因扭曲而造成彎曲應力。檢查完成後就要執行測壓與滲漏工作：

測壓與滲漏工作（要邊口述邊動作檢查）：首先一人至駕駛艙將液壓系統之斷電器、電門與電瓶電門復位。將液壓泵開啟（或是外接液壓試驗車），開始建壓（測試壓力應由小漸大），另一人則至已裝置完成之管路接頭兩端放置漏油聚油盆，並先以吸油布擦拭，並觀察接縫處有無滲油現象（若發現滲油則關機，再用扭力扳手再循序加磅至最大扭力值，若無效將按規定重新拆裝作業）。

**2.** 工作完成注意場地清理與工具歸位。

**Main points to lock in:**
- Check straight-line marking first (扭曲 = bad, causes 彎曲應力)
- Two-person test:
  - **Person A (cockpit):** reset breaker/switch/battery switch → turn on pump or hook up test cart → build pressure **小漸大** (gradually)
  - **Person B (at fitting):** place 聚油盆 under both ends → wipe with 吸油布 → watch seam for leaks
- If leaking → shut down → torque wrench up in steps to max value → if still leaking, redo the whole disassembly/install
- Last step no matter what: **場地清理 + 工具歸位** (clean site, put tools back)
